# v16三级证据分级与越级审计

## 1 判定规则

- **W1 直接可穿戴证据**：使用头带、耳内、贴附式、移动端或其他可实际佩戴设备，在人体睡眠中完成信号采集、在线识别或刺激控制。可穿戴监测研究仅支撑输入、佩戴和居家可用性，不能自动升级为干预疗效证据。
- **W2 可迁移睡眠闭环证据**：直接研究睡眠阶段、事件、相位算法或睡眠刺激效应，但主要依托实验室PSG、高密度EEG、台式系统或尚未闭合的算法链路。可用于确定算法、范式和效应边界，不能直接证明居家可穿戴性能。
- **W3 邻近工程、机制与背景证据**：流行病学与指南、动物研究、侵入式系统、非睡眠同步平台、开放环环境干预或非目标模态算法。仅用于背景、机制、同步、伪影、风险或设计参照，不能替代人体可穿戴闭环验证。

辅助标签按需使用：`HUMAN`、`ANIMAL`、`LAB`、`HOME`、`ONLINE`、`REPLAY`、`OFFLINE`、`REVIEW`、`GUIDELINE`、`PREPRINT`、`ENGINEERING`。

## 3 章节使用规则

| 章节 | 主证据 | 辅助证据与限制 |
|---|---|---|
| 第1章 | W1、相关综述 | W2说明闭环原理；W3仅用于疾病负担、指南和术语背景 |
| 第2章 | W1 | W2用于算法和评价方法；W3不得证明可穿戴在线性能 |
| 第3章 | W2为主，W1用于落地 | W2生理与行为结果不得直接外推至居家可穿戴疗效 |
| 第4章 | W1与W2 | W3仅作侵入式、外部相位或邻近工程参照 |
| 第5章 | W1必须作为系统成熟度核心 | W2用于刺激范式；W3用于边界比较，不进入可穿戴成熟度排序 |
| 第6章 | W1决定可穿戴证据缺口 | W2、W3不得补齐长期安全和临床疗效缺口 |
| 第7章 | 主要归纳W1结论 | W2支持可迁移方向；W3仅说明背景与未来工程路径 |

## 4 逐章越级审计结果

| 章节 | 原有风险 | v16处理 |
|---|---|---|
| 摘要与1.4 | 未明确非可穿戴研究的纳入理由 | 加入W1/W2/W3范围说明，明确后两类不得替代直接可穿戴证据 |
| 第2章 | 离线算法可能被读作可穿戴在线能力 | 将其限定为候选算法或可迁移方法；直接可穿戴结论仅由W1支撑 |
| 第3章 | 大量实验室CLAS结果可能被外推为可穿戴疗效 | 章首先声明W2为主，章末单列可穿戴落地边界 |
| 第4章 | tACS、REM实验室研究和Dormio可能混为同一成熟度 | 按W1/W2/W3说明各自只支撑事件、相位或交互环节 |
| 第5章 | 系统表缺少直接的证据层级列 | 表5-4增加W1/W2/W3列，非可穿戴系统不进入产品成熟度比较 |
| 第6章 | W2/W3可能被用于概括长期安全与临床效果 | 明确长期安全、居家依从性和临床疗效必须由W1人体多夜证据回答 |
| 第7章 | 总结可能把全部闭环研究概括为可穿戴成果 | 分开陈述W1已支持的技术可行性、W2提供的可迁移证据及W3的参照作用 |

## 5 分级解释边界

- W1表示研究与可穿戴链路直接相关，不表示研究已经达到临床有效、长期安全或产品化成熟。
- W2并非低质量证据，而是与可穿戴落地之间仍存在设备、场景或链路迁移距离。
- W3可具有很高的方法学或机制质量，但不能回答可穿戴睡眠闭环系统在人体居家环境中的直接性能。
- 证据层级与研究质量、偏倚风险相互独立；本分级不替代正式质量评价工具。
