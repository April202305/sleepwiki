# 简化综述协作操作手册：证据核对与单人确认

本手册适用于 [[review/可穿戴睡眠检测与闭环干预综述]]。文献准备仍独立完成；从“阅读已准入文献”到“生成正文”合并为一次操作。只需要一位确认者决定段落是否放行。唯一进度记录见 [[review/综述写作看板]]，唯一已确认正文见 [[review/综述正文草案]]。

## 一、角色边界

| 角色 | 可以做 | 不能做 |
| --- | --- | --- |
| 撰写者 | 提出文献需求、处理用户放入 `raw/inbox/` 的素材、核对证据、生成一个草案与逐句矩阵、更新看板 | 用未提供文献补写、跳过来源定位 |
| 确认者（一人） | 对照原文与矩阵，作出确认/返工/缺证据决定 | 跳过逐句核验，把无来源信息放行 |
| 下载代理 | 仅按 [[review/文献清单/文献下载清单]] 下载并返回完整全文、版本与文件核对信息 | 自行扩展题录、决定引用资格、写入 `raw/` |
| 用户 | 接收下载代理交付并放入 `raw/inbox/`，可担任确认者 | 要求智能体以未入库全文写正文 |

同一个人可兼任撰写者与确认者；但在确认时必须重新逐句对照原文和证据矩阵。

## 二、状态与放行门槛

```text
待开始
  → 文献准备
  → 证据核对与生成
  → 待确认
  → 已确认 → 写入正文草案 → 整合小节
        ↘ 需返工 → 证据核对与生成
        ↘ 阻塞：缺证据 → 用户补全文 → Ingest → 文献准备
```

| 当前状态 | 谁操作 | 允许进入下一步的条件 | 下一状态 |
| --- | --- | --- | --- |
| 待开始 | 撰写者/用户 | 已明确一个最小段落和它要回答的问题 | 文献准备 |
| 文献准备 | 撰写者 | 拟用文献均已 Ingest，或已清楚登记 `gap` | 证据核对与生成 / 阻塞：缺证据 |
| 证据核对与生成 | 撰写者 | 已交付一个草案、待补资料、主张表和逐句矩阵 | 待确认 |
| 待确认 | 确认者（一人） | 完成逐句原文、范围、层级、限制和上下文检查 | 已确认 / 需返工 / 阻塞：缺证据 |
| 已确认 | 撰写者 | 确认结论和修改历史已登记 | 写入正文草案；可开始下一段 |
| 需返工 | 撰写者 | 已逐条处理意见并提升版本号 | 证据核对与生成 |
| 阻塞：缺证据 | 用户/撰写者 | 用户补齐完整资料并完成 Ingest | 文献准备 |

## 三、每一轮的标准操作

### 步骤 A：选段、需求、下载与 Ingest

**撰写者或用户发送：**

```text
【综述协作｜阶段 0：文献需求单】

目标段落：1.1 睡眠障碍的疾病负担与睡眠干预的临床需求
目标字数：250–300 字
目标问题：睡眠障碍带来什么疾病/社会负担？为什么需要睡眠干预？
本轮动作：只生成文献需求单，不写正文。
```

**撰写者交付：** 必需/推荐/背景文献候选、每篇要提取的字段、不可替代的证据、缺口与检索关键词；不写正文。

**可进入下一步，当且仅当：** 候选已登记到 [[review/文献清单/文献下载清单]]，并由用户放入 `raw/inbox/`、完成 Ingest；或已明确某项保留为 `gap`。

**下载代理执行：** 只按 [[review/文献清单/文献下载清单]] 返回完整 PDF、版本和文件核对信息。**用户执行：** 将合格 PDF 放入 `raw/inbox/`，再发送：

```text
【综述协作｜阶段 2：素材录入】

处理 raw/inbox 全部素材。
```

**撰写者交付：** 来源页、实体词条、证据矩阵更新、准入/不准入清单及不准入原因。

**可进入下一步，当且仅当：** 每篇拟引用文献都有可读全文、稳定 `source_id`、来源页和页码/表图定位；否则回到补文献。

### 步骤 B：证据核对与单段生成（合并步骤）

**撰写者或用户发送：**

```text
【综述协作｜阶段 3：证据核对与生成】

目标段落：1.1-P1
只用：A、B、C 三篇已准入文献。
本轮动作：一次完成全文核对、待补资料、主张表、一个段落、段落核验清单和逐句文献证据矩阵。
```

**撰写者交付：** 待补资料（如有）、主张表、一个段落、段落核验清单和逐句段落文献证据矩阵（本文句子—原文短语—来源页—页码/表图—条件—限制）。同时将看板状态更新为 `待确认`。

**可进入下一步，当且仅当：** 段落中的每个事实都在矩阵中有原文指针；无来源内容已移出正文或标为 `【待补证据】`。

### 步骤 C：单人确认与决定

**确认者发送：**

```text
【综述协作｜阶段 4：单人确认】

确认第 1.1-P1 v1。
本轮动作：由一人逐句对照原文和矩阵，结论仅可为“确认 / 返工 / 缺证据”。
```

**确认者执行：** 按范围、来源、原文忠实度、证据层级、方法比较、完整性和上下文衔接逐句检查。

**确认者交付：** `已确认`、`需返工` 或 `阻塞：缺证据`；逐句理由、缺失资料和下一动作均写入 [[review/综述写作看板]]。

**可进入下一步：**

- `已确认`：撰写者写入正文草案，可开始下一段；
- `需返工`：撰写者只改该段，版本号升为 v2 后重新确认；
- `阻塞：缺证据`：回到步骤 A，不写结论性正文。

### 步骤 D：合并与章节推进

**撰写者或确认者发送：**

```text
【综述协作｜阶段 5：小节整合】

整合第 1.1 节。
本轮动作：仅合并已确认段落，不添加新事实。
```

**撰写者交付：** 仅合并所有“已确认”的段落到 [[review/综述正文草案]]，更新章节页、证据矩阵和看板。

**可进入下一节，当且仅当：** 本节所有目标问题已回答或已明确登记为 `gap`；没有未处理的 `需返工`；段落之间没有证据层级跳跃。

## 四、每日收尾命令

```text
【综述协作｜每日收尾：更新看板】

更新综述写作看板。
更新范围：段落版本、生成/确认状态、责任人、缺失资料、下一步和修改历史；不改写正文。
```

撰写者或确认者需更新：当前段落版本、生成/确认状态、责任人、缺失资料、下一步和修改历史。该命令不改写正文。
