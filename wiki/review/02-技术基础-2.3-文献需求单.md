# 第 2.3 节文献需求单：闭环系统的延迟与精度

服务章节：[[review/chapters/02-基础理论与核心概念]]；下载交接：[[review/文献下载清单]]；阶段 3 受限交付：[[review/02-技术基础-2.3-P1-证据包]]。

## 段落问题与边界

- 目标问题：阶段级、事件级和相位级识别结果进入闭环刺激决策时，系统的时间误差由哪些环节构成；在目标事件持续时间有限的条件下，检测/相位精度、误触发、漏触发、拒绝触发与总时延如何共同决定其是否适合闭环？
- 建议字数：800–1,000 字。
- 本节叙事顺序：**时延口径与统一时间基准 → 阶段级门控延迟 → 事件级检测延迟 → 相位级估计/刺激误差 → 精度—延迟权衡及不可比边界**。
- 每项系统必须尝试拆分：采集/ADC、窗口或缓冲、预处理、推理/检测、决策、通信、刺激设备执行、端到端总时延；同时记录时钟同步、抖动与延迟校准方法。
- 精度字段必须按输出层级分开：阶段级用灵敏度、特异度、κ/F1 及状态切换延迟；事件级用 precision、recall、F1、误/漏触发及相对专家起点的检测延迟；相位级用目标相位、圆统计误差/离散度、命中窗口和刺激抵达时刻。
- 不写：传感器佩戴和信号质量主体（2.1）；算法架构主体（2.2）；刺激带来的生理、认知或临床获益（第 3–5 章）。计算耗时、检测延迟、ERP 潜伏期和端到端时延不得互相替代。

## 最小下载组合与放行条件

1. **当前证据结构：**4 份新增资料均已准入，补足居家触发精度、FPGA 台架吞吐量、纺锤波实时回放和固定步长/PLL 比较；但仍没有统一时钟下采集至声音抵达的完整端到端时延与抖动，2.3 继续 `阻塞：缺证据`。
2. **最低放行组合：**优先取得 `DL-2.3-001`；若其未报告可核验的总时延，则必须再取得 `DL-2.3-002`。同时至少取得 `DL-2.3-003` 或一篇等价的人体在线事件检测—刺激研究，以补误/漏触发及停止条件。
3. **建议组合：**`001 + 002 + 003`；若需要讨论感知形态对时延的影响，再加入 `004`。`005` 仅用于加强相位级实现。
4. **放行门槛：部分满足。**Hassan 已补在线回放的 precision/recall/F1，但缺实际刺激；总时延门槛仍未满足。必须继续补一篇报告端到端测量方法、数值与抖动的在线人体或完整台架系统研究。
5. **不可接受的替代：**仅离线分期准确率、只给模型参数量/FLOPs、只给推理时间、仅报告相位直方图而无触发时间基准、产品宣传、动物或非睡眠系统，均不能单独解除 2.3 的阻塞。
6. **比较规则：**只有人群、信号/导联、目标阶段或事件、参考真值、时间零点、窗口、运行模式和时延定义一致时才可作数值比较；否则统一标注 `⚠️不可直接比较`。
7. **阶段 3 状态：已完成受限生成。**现有局部证据足以区分计算耗时、检测延迟、预设间隔与端到端时延，并形成 [[review/02-技术基础-2.3-P1-证据包]]；统一时钟下的完整总时延与抖动继续登记为 `gap`，不得据此形成跨系统实时性能排行。
