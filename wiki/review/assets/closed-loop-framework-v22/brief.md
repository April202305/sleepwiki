# 双面板图语义简报

目标：独立可编辑draw.io + PNG + 17 cm矢量PDF，不替换现有论文。内容源为[[review/格式/闭环睡眠干预综述-v22.tex]]，风格源为用户提示；不使用实物资产或生成图片。

| 要求 | 依据 | 编码 |
|---|---|---|
| 五阶段主链 | 1.2—1.3；2.1—2.3，[3,7—10] | a面板从左到右 |
| 因果识别、可选模态 | 2.1—2.2，[11,15—16,22,32] | 短标签；非全部必需 |
| 安全反馈与可选自适应分开 | 4.5，[40,48]；1.2 | 实线返回与虚线返回 |
| 物理输出与响应 | 2.3，[9—10,36] | 受试者文字与持续采集标签 |
| 评价而非疗效承诺 | 1.4、5.4 | 独立记录评价区域，珊瑚色仅标题 |
| 准入与拒绝、暂停与恢复 | 4.5 | b面板三个条件、拒绝分支、暂停与重新判断 |

不绘制：具体神经网络、张量、训练损失、虚构性能、W1—W3数量或证据强度。W1—W3继续由论文图2承担。
安全反馈是综合设计关系，不承诺每个研究完整实现。阈值、剂量与恢复条件不虚构数值。阶段、事件、相位按范式选用。
连线起止、类型和路径保存在drawio的source/target及几何节点中；全部禁止穿越其他模块。日志连线不表示实时控制。
来源角色：论文=科学内容；提示词=结构和风格；技能=质量流程。图为作者组织的综合框架，不是新算法。

导出边界：本机无draw.io CLI；用随附受限XML渲染器读取同一个drawio生成PDF/SVG，PNG从PDF渲染。仅支持本图使用的矩形、文本和折线；draw.io原生渲染仍需用户打开复核。
