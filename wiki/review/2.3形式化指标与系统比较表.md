# 2.3形式化指标与系统比较表

本页对2.3现有8项核心来源进行专项字段提取，服务于[[review/证据包/02-技术基础-2.3-P1-证据包]]和[[review/章节证据矩阵/第2章-技术基础证据矩阵]]。`NR`表示原文未报告或现有全文中未能可靠定位；不得将`NR`解释为该环节不存在。[[source-pages/haggerty-2026-thalamus]]不进入核心8项，仅作为6.3的统一时钟、负载和失效保护邻近工程参考。

## 一、时延形式化定义

一次候选刺激机会的端到端时延定义为：

\[
T_{\mathrm{total}}=T_{\mathrm{wait}}+T_{\mathrm{acq}}+T_{\mathrm{buffer}}+T_{\mathrm{pre}}+T_{\mathrm{infer}}+T_{\mathrm{decision}}+T_{\mathrm{comm}}+T_{\mathrm{device}}+T_{\mathrm{physical}}.
\]

| 符号 | 起点—终点 | 与其他量的边界 |
| --- | --- | --- |
| \(T_{\mathrm{wait}}\) | 候选生理事件开始—形成足以判定的波形/窗口 | 是“窗口尚未形成”的等待，不是模型执行时间 |
| \(T_{\mathrm{acq}}\) | 电极端生理信号—ADC/采集时间戳 | 应注明采样与数据块形成方式 |
| \(T_{\mathrm{buffer}}\) | 数据到达—分析窗口可用 | 窗长、步长与缓冲实现分别登记 |
| \(T_{\mathrm{pre}}\) | 窗口可用—预处理输出 | 包括因果滤波、重采样、特征计算；零相位事后分析不得计作在线链路 |
| \(T_{\mathrm{infer}}\) | 模型输入—分类/事件/相位输出 | 仅为算法执行时间，不代表响应延迟 |
| \(T_{\mathrm{decision}}\) | 模型输出—触发/拒绝决定 | 包括阈值、置信度、阶段门控、不应期和剂量上限 |
| \(T_{\mathrm{comm}}\) | 触发决定—刺激设备收到命令 | 有线、无线、操作系统及队列等待均属此项 |
| \(T_{\mathrm{device}}\) | 设备收到命令—换能器产生物理输出 | 包括声卡/音频缓冲、DAC和驱动器启动 |
| \(T_{\mathrm{physical}}\) | 换能器输出—声音真正到耳/骨传导到达 | 应以麦克风、人工耳或物理回环测量；软件调用时间不能替代 |

编程补偿间隔\(T_{\mathrm{programmed}}\)、ERP/听觉通路潜伏期\(T_{\mathrm{physiology}}\)和上述实测系统时延必须单独登记，不得相加或互换，除非原研究明确给出同一时间基准下的测量关系。

## 二、时延统计与时钟字段

每个环节优先登记均值、SD、中位数、IQR、P90、P95、P99和最大值；若只报告“均值±某统计量”，必须沿用原文定义，不能自动解释为抖动。本文将抖动记作同一环节重复测量的离散性，优先使用SD、IQR或P95−P50，并注明单位是刺激、夜晚还是受试者。

时钟字段至少包括：采集时钟、算法时钟、刺激设备时钟、同步方法、固定偏移、漂移和同步残差。不同设备各用独立时钟而未同步时，软件时间戳不得直接支持声音到耳端到端时延。

## 三、刺激机会结果定义

| 结果 | 操作定义 | 不得混同 |
| --- | --- | --- |
| 成功刺激 | 有合格目标，刺激实际到达且落入规定时间/相位窗 | 仅“发出命令”不等于成功到达 |
| 漏失 | 存在合格目标，但系统未触发或未在目标窗到达 | 不与主动安全拒绝合并 |
| 安全拒绝 | 因信号质量、低置信度、觉醒/阶段变化、不应期或剂量上限主动不刺激 | 拒绝可能是正确的安全控制 |
| 误触发 | 无合格目标却实施刺激，或落在错误阶段/事件 | 阶段误触发与事件误触发应分开 |
| 执行失败 | 已形成刺激命令，但通信、设备或换能器未产生输出 | 不等于检测漏失 |
| 时机失败 | 刺激已到达，但超出目标相位窗或事件有效窗 | 必须以实际到达时间判断 |

机会成功率记为\(N_{\mathrm{success}}/N_{\mathrm{eligible}}\)。同时分别报告漏失率、拒绝率、误触发率、执行失败率和时机失败率；没有候选机会总数时不得反推这些比率。

## 六、允许比较与不可比边界

允许直接或条件化比较：

- 同一研究内改变检测阈值、门控规则或相位算法，且时间零点与真值不变；
- 同一研究内把\(T_{wait}\)与\(T_{infer}\)分开，例如SpindleNet的事件起点延迟与约6 ms执行时间；
- Debellemaniere同一协议内的N3混淆计数、阶段分布、相位命中和剂量/暂停规则；
- Portiloop同一系统内的阈值—precision/recall—检测延迟关系。

必须标记`⚠️不可直接比较`：

- 30 s阶段窗口、250/520 ms事件窗口与慢波相位触发；
- 在线人体、预录回放、离线事后相位和仅计算触发；
- 模型执行时间、事件检测延迟、编程补偿间隔、ERP潜伏期和声音到耳时延；
- 平均值、均值±SD、范围、分位数和最大值；
- 专家OR/AND起点、离线算法共识和离线零相位Hilbert相位；
- 有实际声音剂量的系统与居家夜未播放声音的Ferster 2019；
- 缺少共同时间基准、设备同步或物理输出测量的跨系统毫秒数。

### 本批闭合判断
