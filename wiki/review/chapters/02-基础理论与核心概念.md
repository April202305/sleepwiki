# 2 闭环睡眠干预的技术基础

章节地图：[[review/可穿戴睡眠检测与闭环干预综述]]。

## 2.1 可穿戴传感与实时信号处理

- 记录模态、质量控制、伪影、同步方案及居家佩戴限制。
- 可穿戴人工智能的筛查/诊断应用范围及治疗缺口背景：[[concept/可穿戴人工智能]]、[[source-pages/aziz-2025-wearable-ai-sleep-disorders]]；⚠️该范围综述不能替代具体设备的信号质量或实时性证据。
- 现有背景资料：[[concept/可穿戴 EEG]]、[[concept/耳内 EEG]]、[[concept/PSG 参考标准]]、[[source-pages/de-gans-2024-eeg-wearables-systematic-review]]、[[source-pages/mikkelsen-2019-ear-eeg-whole-night-sleep]]、[[source-pages/pazuelo-2024-in-ear-signal-quality]]、[[source-pages/mohamed-2023-wearable-eeg-review]]、[[source-pages/debellemaniere-2018-ambulatory-dry-eeg-closed-loop]]、[[source-pages/bressler-2023-wearable-eeg-closed-loop]]。
- 文献需求与下载门槛：[[review/文献清单/02-技术基础-2.1-文献需求单]]。⚠️已覆盖头带/干 EEG 与耳内 EEG；原定多模态贴附式睡眠研究（DL-2.1-002）仍未取得，现有纹身电极材料不得替代。
- 阶段 3 交付：[[review/证据包/02-技术基础-2.1-P1-证据包]]，包含 `2.1-P1 v1` 草案与逐句矩阵；当前待一人确认，尚未并入正文。

## 2.2 实时睡眠分期与瞬时相位估计技术

- 分期、事件检测与相位估计必须分开评价；离线模型不得视为实时模型。
- 既有离线背景：[[concept/睡眠分期]]、[[concept/单通道 EEG]]、[[source-pages/phan-mikkelsen-2022-automatic-sleep-staging]]。
- 已准入的阶段/事件/相位资料：阶段级 [[source-pages/patanaik-2018-end-to-end-real-time-sleep-staging]]；事件级 [[source-pages/valenchon-2022-portiloop]]、[[source-pages/kulkarni-2019-real-time-spindle-detection]]；相位级 [[source-pages/ferster-2022-real-time-phase-algorithms]]、[[source-pages/bressler-2023-wearable-eeg-closed-loop]]；方法边界见 [[source-pages/esfahani-2023-closed-loop-auditory-principles]]。
- 文献需求与下载门槛：[[review/文献清单/02-技术基础-2.2-文献需求单]]。三类最小直接证据已齐，可进入阶段 3；⚠️Patanaik 的在线上下文替代和双向滤波须保留，不能概括为全链路严格因果；Kulkarni 的事件检测延迟不能替代阶段或系统总时延。
- 阶段 3 交付：[[review/证据包/02-技术基础-2.2-P1-证据包]]，包含 `2.2-P1 v1` 草案与逐句矩阵；当前待一人确认，尚未并入正文。

## 2.3 闭环系统的延迟与精度

- 每项研究拆分采集、缓冲、预处理、推理、决策、通信、执行与总时延。
- 缺任一时延或触发误差字段，标记 `待核实`，不宣称满足实时性。
- 当前可用局部证据：[[source-pages/esfahani-2023-closed-loop-auditory-principles]] 的时延构成；[[source-pages/valenchon-2022-portiloop]] 的 64 ms 常数延迟与误/漏触发口径；[[source-pages/kulkarni-2019-real-time-spindle-detection]] 的执行时间/检测延迟；[[source-pages/debellemaniere-2018-ambulatory-dry-eeg-closed-loop]] 与 [[source-pages/ferster-2022-real-time-phase-algorithms]] 的阶段/相位精度；[[source-pages/patanaik-2018-end-to-end-real-time-sleep-staging]] 与 [[source-pages/bressler-2023-wearable-eeg-closed-loop]] 仅提供局部时间参数。
- 文献需求与放行门槛：[[review/文献清单/02-技术基础-2.3-文献需求单]]。⚠️当前仍缺至少一篇报告可核验分段或端到端时延、并与在线触发精度相连的直接系统研究，故 2.3 保持 `阻塞：缺证据`。
- 新准入资料：[[source-pages/ferster-2019-mobile-closed-loop-acoustic]]、[[source-pages/hassan-2022-real-time-spindle-detection]]、[[source-pages/sun-2023-fpga-sleep-modulation]]、[[source-pages/piorecky-2021-real-time-slow-oscillation]]。它们补足局部字段，但计算吞吐量、硬件接口延迟和预设刺激间隔均不能替代总时延。
- 阶段 3 受限交付：[[review/证据包/02-技术基础-2.3-P1-证据包]]，包含 `2.3-P1 v1` 草案与逐句矩阵；当前待一人确认，尚未并入正文。完整端到端总时延与抖动仍为 `gap`。
