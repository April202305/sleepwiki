# 章级证据矩阵目录

本目录将各小节证据包按大章合并展示，便于逐章核验。[[review/证据矩阵]] 仍是唯一证据登记表；本目录不新增事实、调整证据类型或替代原文定位。

## 维护规则

- 新证据先登记到 [[review/证据矩阵]]，再更新相应小节证据包。
- `direct`、`synthesis` 与 `gap` 的定义、定位和限制以原证据包及总矩阵为准。
- 章级页面使用嵌入方式合并，不复制或改写小节证据，避免多份表格发生漂移。
