# 5.4典型闭环系统横向比较表

本表不回答“有哪些产品”，而回答各系统把“感知—识别—决策—刺激—验证”推进到哪一步。`NR`表示全文未报告；`不适用`表示该系统没有实施相应任务；`gap`表示5.4需要但现有知识库没有可准入的直接证据。任何`NR`不得解释为系统不存在该能力。

## 一、系统准入与验证层级

| 层级 | 定义 | 本表系统 |
| --- | --- | --- |
| A 完整人体闭环 | 人体睡眠信号在线进入决策并实际实施刺激 | WDD、Portiloop v2、ENMod、Earable、MHSL-SB多夜试验、TSB Axo、CLAS-hdEEG、Henao耳内闭环 |
| B 端侧事件闭环工程 | 实时完成事件检测和刺激控制，但人体疗效链未闭合 | Portiloop工程标定 |
| C 闭环候选 | 有可穿戴/PSG/居家验证，但没有检测—刺激直接全文 | 干接触耳内EEG、Naox耳内EEG |
| D 设计/邻近证据 | 评价交互体验或局部工程环节，不验证核心EEG闭环性能 | Dozer；另见5.4邻近技术文本框 |

## 二、设备族关系核验

| 系统族 | 已核验关系 | 不允许的合并 |
| --- | --- | --- |
| ENMod/Bressler | ENMod即Bressler 2023所述Elemind Neuromodulation Device；同一行登记 | 不得把“ENMod”和“Bressler系统”计成两个系统 |
| MHSL-SB/Ferster/Lustenberger | Ferster 2019是MHSL-SB工程与计算触发研究；Lustenberger 2022明确使用MHSL-SB实施多夜居家刺激，可作为同一系统族的工程—人体配对 | 两篇的样本、夜数、是否实际刺激和终点必须分开 |
| TSB Axo/Kasties | Kasties 2025明确使用Tosoo Sleep Band Axo | 现有全文不能证明TSB Axo与MHSL-SB为同一硬件或可无缝合并；暂列独立系统 |
| WDD/Debellemanière | Debellemanière 2018明确验证Wireless Dreem Device | Debellemanière 2022的实验室14导系统没有充分证据证明为同一WDD版本，不并入WDD系统族 |
| Portiloop | Valenchon 2022为工程标定；Jourde 2025使用Portiloop v2完成居家人体纺锤闭环 | 可合并为系统族验证链，但版本不同，不得称同一硬件版本 |
| 耳内EEG | Henao 2022直接验证实验室午睡耳内检测—声音刺激；Mikkelsen与Naox只验证采集/PSG | 不得把Henao实验室原型外推为成熟居家多夜耳内系统 |

## 四、字段覆盖与不可比边界

| 字段 | 覆盖较强 | 主要缺口 |
| --- | --- | --- |
| 分期性能 | WDD、Earable、耳内候选 | 系统使用不同标签、导联、人群和划分；不可排名 |
| 事件检测 | Portiloop | 人体刺激系统很少报告event-wise指标、假阳性/小时及机会分母 |
| 相位命中 | WDD、MHSL-SB计算触发、CLAS-hdEEG DIN标记 | 物理声音到达、统一离线真值和圆周离散统计不完整 |
| 端到端时延 | Portiloop工程链、CLAS-hdEEG检测至DIN | 采集至声音到耳、P95/P99、最大值和整夜抖动普遍缺失 |
| 生理响应 | WDD、ENMod、MHSL-SB、TSB Axo、CLAS-hdEEG | 终点与时窗异质，不能统一效应量 |
| 临床终点 | 基本没有疾病治疗级直接证据 | 入睡潜伏、记忆或日间功能不能互相替代 |
| 居家多夜 | MHSL-SB、Earable、ENMod、耳内候选 | 有效夜、失败夜、剔除规则和退出分母不统一 |
| 安全停止 | WDD、TSB Axo、MHSL-SB部分覆盖 | 每项机会的拒绝、执行失败、超窗及剂量上限普遍NR |

必须标记`⚠️不可直接比较`：阶段accuracy与事件precision；模型推理与生理检测等待；DIN/软件标记与声音到耳；实验室、回放和居家人体；健康人与疾病人群；会话数与独立受试者；剔除失败夜后的性能与整体可用性；短期生理响应与临床疗效。

## 五、系统核心准入初判

- 核心横向表：WDD、Portiloop系统族、ENMod、Earable、MHSL-SB系统族、TSB Axo、CLAS-hdEEG、Henao耳内闭环。
- 候选但不进入闭环性能排行：干接触耳内EEG/Naox。
- 产品交互参照：Dozer。
- 明确缺口：居家多夜耳内EEG闭环、统一失败夜分母、物理端到端时延、Portiloop同设备版本配对。
