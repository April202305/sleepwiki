# 第 3.1 节文献需求单：锁相听觉刺激的原理与范式演进

服务章节：[[review/chapters/03-可穿戴睡眠信号采集硬件体系]]；下载交接：[[review/文献清单/文献下载清单]]。本页只定义证据需求与下载任务，不生成正文。

## 段落问题与边界

- 目标问题：锁相听觉刺激如何从随机初始相位或固定序列间隔的开放环方案，演进为依据 NREM/N3、慢振荡事件、目标相位和即时响应安排刺激的闭环范式？
- 建议字数：700–850 字。
- 叙事顺序：**慢振荡相位与刺激时机 → 开放环操作基线 → 阶段门控与相位触发 → 固定延迟向预测/PLL 演进 → 剂量、自限性与即时反馈 → 实验室向居家可穿戴迁移**。
- 每项研究必须提取：人群与睡眠条件、EEG 导联/参考、目标阶段与事件、目标相位及定义、检测与预测方法、声音类型/声压/时长、单次脉冲数、脉冲间隔、不应期、每夜累计剂量、觉醒/阶段改变停止规则、运行模式及验证层级。
- 不写：慢波/纺锤波增强效果的系统比较（3.2）；记忆或认知疗效比较（3.3）；失眠、MCI/AD 等临床队列疗效（3.4）；端到端时延排行（2.3）。本节可提及这些终点用于解释范式设计，但不得提前下疗效结论。

## 最小下载组合与放行条件

1. **最低组合：**`DL-3.1-001 + DL-3.1-002 + DL-3.1-003`。三篇分别补经典闭环协议、自限性/剂量响应和跨年龄时机差异；缺任一篇都无法完整回答“范式如何演进”。
2. **方法增强：**加入 `DL-3.1-004`，用于建立固定延迟—PLL—后续多算法基准的可追溯技术链；若无法取得，可由已准入 Ferster 2022 与 Piorecky 2021 受限替代，但须注明缺早期 PLL 原始协议。
3. **设备与剂量增强：**`DL-3.1-005` 补声音参数，`DL-3.1-006` 补耳内系统；两者为推荐项，不阻塞只讨论额区/干 EEG 与既有声音协议的受限草案。
4. **阶段 3 放行门槛：**至少取得三篇必需全文，并能同时核验目标相位、触发规则、声音参数、序列/间隔、不应期或停止条件，以及各自运行/验证模式；否则 3.1 保持 `文献准备` 或 `阻塞：缺证据`。
5. **不可接受的替代：**仅算法相位误差、仅摘要、设备宣传、只报告记忆结果而缺刺激协议、动物研究或非睡眠刺激，均不能单独替代本节的人体范式证据。
6. **比较规则：**人群、导联、阶段门控、相位零点、声音剂量、刺激序列、运行模式或对照条件不一致时，统一标记 `⚠️不可直接比较`，不得给出“最佳范式”排名。
