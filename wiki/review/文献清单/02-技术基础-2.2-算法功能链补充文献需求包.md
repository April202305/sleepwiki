# 第 2.2 节算法功能链补充文献需求包

本需求包服务于 [[review/综述正文v5草案-2.2至6.5]] 后续版本的 2.2 节重构。目标是把现有按模型名称展开的叙述改为“epoch 内表征—epoch 间上下文—输出与后处理—在线实现—部署与泛化”的算法功能链，并补强事件检测、相位估计、数据泄漏、类别不平衡和人工评分参考标准。

本页仅规定需要取得的研究类型、数量、质量和提取字段。候选题录必须来自现有 [[review/文献检索结果]]、后续经用户批准的检索结果或用户明确提供的题录；未核验全文前不得生成论文名称、作者、DOI 或正文结论。

## 一、现有证据基线

现有总矩阵约有 16 项与 2.2 相关的来源，其中可直接用于核心算法比较的约 11–12 项。其余为方法综述、工程台架或邻近技术证据。

已覆盖的主要路线包括：

- 手工特征与随机森林：[[source-pages/mikkelsen-2019-around-ear-rf-staging]]；
- CNN—双向 RNN—注意力：[[source-pages/mousavi-2019-sleepeegnet]]；
- 分层双向 RNN：[[source-pages/phan-2019-seqsleepnet]]；
- Transformer：[[source-pages/phan-2022-sleeptransformer]]、[[source-pages/guo-2024-flexsleeptransformer]]；
- EEG 状态空间模型：[[source-pages/huang-2025-multisess]]；
- 阶段级在线输出：[[source-pages/patanaik-2018-end-to-end-real-time-sleep-staging]]；
- 纺锤波事件检测：[[source-pages/kulkarni-2019-real-time-spindle-detection]]、[[source-pages/valenchon-2022-portiloop]]、[[source-pages/hassan-2022-real-time-spindle-detection]]；
- 慢波/α 相位估计：[[source-pages/ferster-2022-real-time-phase-algorithms]]、[[source-pages/santostasi-2015-pll-acoustic-stimulation]]、[[source-pages/piorecky-2021-real-time-slow-oscillation]]、[[source-pages/bressler-2023-wearable-eeg-closed-loop]]。

现有材料仍不足以完成严格因果在线模型、评分参考标准、数据泄漏、不确定性/拒绝输出、统一事件评价、相位真值和设备端资源的系统比较。

## 二、数量目标

### 理想目标

- 2.2 最终不重复文献总量：30–34 篇；
- 本轮新增全文：14–16 篇；
- 中文文献占 2.2 最终不重复文献总量的比例不得低于 20%；按向上取整计算，最终 30 篇时至少 6 篇，31–34 篇时至少 7 篇；
- 本轮新增 14–15 篇时至少纳入 3 篇中文文献，新增 16 篇时至少纳入 4 篇中文文献；若现有文献池中的合格中文文献不足以使最终比例达到 20%，本轮须继续补足，不能只满足新增批次比例；
- 其中 A 级核心证据不少于 10 篇；
- 中文文献中至少 2 篇达到 A 级核心证据标准；中文标准、指南或高质量方法综述可计入 B 级，但不得代替这 2 篇中文核心原始研究；
- 标准、评分或高质量方法文献不少于 2篇；
- 在线、因果或流式原始研究不少于 5篇；
- 外部验证或跨设备研究不少于 3篇；
- 预印本最多 2篇；
- 邻近技术证据最多 2篇，且不得替代核心 EEG 睡眠证据。

### 最低放行目标

- 本轮至少新增 10 篇合格全文；
- 本轮新增中文文献至少 2 篇，并确保合并现有来源后中文文献比例仍不低于 20%；
- A 级核心证据至少 7篇；
- 严格因果在线 EEG 分期至少 2篇；
- 标签/评分一致性至少 2篇；
- 事件检测评价至少 2篇；
- 相位真值与圆周评价至少 2篇。

若只达到最低目标，2.2 可进行受限改写，但资源部署、拒绝输出或部分算法路线仍须保留 `gap`。

### 中文文献计数口径

- “中文文献”指正文主要语言为中文，且具有可核验正式题录和完整全文的学术来源；仅有中文摘要、中文网页介绍或中文译文的英文论文不计入。
- 可计入类型包括：同行评审中文期刊原始研究、正式发布的中文国家/行业/团体标准、中文学位论文，以及方法与纳入过程透明的中文系统综述。
- 学位论文原则上按 B 级处理；若其研究设计、数据划分、全文方法和结果均完整，可作为补充直接证据，但不得单独承担关键结论。
- 新闻、科普、厂商白皮书、无同行评审会议摘要、仅有题录或无法定位方法和结果的材料不计入 20% 配额。
- 同一研究的中文学位论文、中文期刊稿和英文扩展稿按一项独立研究计数，优先保留信息最完整、正式发表层级最高的版本，避免重复抬高中文比例。
- 中文文献仍须满足对应 R1–R7 的字段要求和质量门槛；不得因语言配额降低因果性、受试者隔离、指标完整性或全文可核验要求。

## 三、质量分级

### A 级：核心直接证据

一篇研究应满足以下多数条件，并且必须具备完整可核验全文：

- 同行评审正式发表版本；
- 人体睡眠 EEG 原始研究；
- 数据集、人群、导联、标签标准和数据划分清楚；
- 算法输入、窗口、上下文方向、滤波、归一化和后处理可定位；
- subject-wise、leave-one-subject-out 或外部测试，且训练/测试受试者隔离；
- 报告 macro-F1、κ、balanced accuracy 或逐类指标中的至少两项；
- 在线研究说明因果性、时间零点、运行环境及延迟口径；
- 阴性结果、失败条件和局限完整报告。

### B 级：补充证据

- 高质量系统综述、标准、评分一致性研究或方法 benchmark；
- 方法和结果完整的预印本；
- 可穿戴工程实现或端侧部署研究；
- 非 EEG、非睡眠或开放环邻近研究。

B 级证据用于定义、比较框架、工程参照或证据缺口，不能替代关键原始人体研究。

### 不准入核心比较

- 只有题录或摘要；
- 产品宣传或无法核验方法和结果的材料；
- 未说明标签标准或训练测试划分；
- 随机 epoch 划分且无法排除受试者泄漏；
- 依赖未来输入却直接宣称实时；
- 只有总体准确率且无 κ、macro-F1 或逐类结果；
- 事件检测未说明事件匹配规则；
- 相位算法未说明参考相位或重建方式；
- 只报告 FLOPs 或桌面 GPU 推理速度，缺少目标硬件实测。

## 四、必需文献任务

### 任务 2.2-R1：严格因果在线 EEG 分期

- 数量：3篇；最低2篇。
- 优先设计：人体 EEG 五分类；在线人体、因果回放或流式端侧验证。
- 路线配额：因果 CNN/RNN 或有限历史模型 1篇；因果 Transformer/流式注意力 1篇；因果 SSM/Mamba 或等价固定状态模型 1篇。
- 必须提取：输入、导联、标签、epoch、历史缓存、未来访问、因果滤波、归一化、网络、后处理、更新步长、逐类指标、参数量、内存、时延、功耗及硬件。
- 不可替代：离线双向模型、仅报告模型 FLOPs、无 EEG 可穿戴模型。

### 任务 2.2-R2：标签标准与人工评分一致性

- 数量：3篇；最低2篇。
- 必需组成：AASM 或正式分期标准 1篇；R&K—AASM/S3—S4 映射研究 1篇；人工评分者间或重复评分一致性研究 1篇。
- 必须提取：标准版本、epoch 长度、阶段定义、S3/S4 合并、评分者数量与经验、单评分/共识方式、逐期一致性和 κ。
- 不可替代：仅引用“PSG 是金标准”的二次表述；事件级专家标注不能单独替代阶段级评分一致性。

### 任务 2.2-R3：数据泄漏与数据划分

- 数量：2篇；最低2篇（分层证据链 R3-A/B/C，非单篇「随机 vs subject-wise 直接比较」命中）。
- 必需组成（分层证据链）：
  - R3-A 数据泄漏机制证据 ≥1 篇：方法学论文、报告规范（如 TRIPOD）或高质量综述，说明随机 epoch 划分为何使同一受试者信息泄漏；
  - R3-B 受试者隔离实践证据 ≥2 篇：采用 subject-wise / LOSO 等严格划分的原始睡眠分期研究；
  - R3-C 外部泛化证据 ≥1 篇：跨数据集或跨中心外部验证。
- 理想证据（非最低放行条件）：同一模型、同一数据集下随机 epoch 与 subject-wise 的直接比较，登记为 `gap`，不阻塞 2.2 重写。
- 必须提取：划分单位、受试者是否重叠、训练/验证/测试数量、数据预处理拟合范围、身份泄漏控制、内部与外部性能差值。
- 不可替代：只采用 subject-wise 但未分析泄漏影响的普通模型论文。
- 结论强度边界：可写「随机划分 epoch 可能使同一受试者数据同时进入训练/测试集，故无法充分检验跨受试者泛化；subject-wise 或外部验证应作为更严格依据」；不可写「随机划分必然造成性能虚高」，不得给出定量虚高百分点（除非有同条件直接比较或自行复现实验）。

### 任务 2.2-R4：事件检测方法与评价 benchmark

- 数量：3篇；最低2篇。
- 路线配额：频带/包络/阈值基线 1篇；传统特征分类器或统一 benchmark 1篇；深度概率输出或在线检测—刺激研究 1篇。
- 必须提取：sample-wise/event-wise、事件匹配规则、重叠阈值或时间容差、precision、recall、F1、假阳性/小时、起点/峰值/终点误差、算法耗时和检测延迟时间零点。
- 不可替代：只报告 sample-wise accuracy；没有事件定义或专家标注方式的研究。

### 任务 2.2-R5：相位真值、预测与圆周统计

- 数量：3篇；最低2篇。
- 路线配额：因果 Hilbert/解析相位比较 1篇；AR 或其他显式预测方法 1篇；神经相位预测或开放 benchmark 1篇。
- 必须提取：输入窗、因果滤波、目标振荡、参考相位生成方式、是否使用离线零相位滤波、刺激前/刺激后重建、圆周均值与离散度、目标窗命中率、低幅慢波表现、延迟补偿及刺激到达时间。
- 不可替代：普通角度算术平均且未说明圆周处理；没有参考相位定义的相位图。

## 五、推荐文献任务

### 任务 2.2-R6：类别不平衡、概率校准与拒绝输出

- 数量：2篇；最低1篇。
- 优先内容：N1/REM 少数类别分析、类别加权或 focal loss、概率校准、selective classification、低置信度拒绝或人工复核。
- 必须提取：逐类支持数、macro-F1、balanced accuracy、校准指标、拒绝覆盖率、拒绝后的性能与阈值设定。
- 使用边界：注意力图、熵或置信度输出不自动等于经过校准的概率或安全拒绝机制。

### 任务 2.2-R7：端侧部署与资源实测

- 数量：2篇；最低1篇。
- 优先平台：MCU、FPGA、手机、耳机/头带本地处理器或其他可穿戴边缘平台。
- 必须提取：参数量、模型大小、峰值内存、输入缓存、数值精度、平均/最大时延、抖动、功耗、整夜续航和硬件型号。
- 使用边界：模型推理时间不等于采集至触发的端到端时延；台架测试与在线人体分别登记。

## 六、背景文献任务

- 数量：2–3篇，不占 A 级核心配额。
- 类型：自动睡眠分期高质量系统综述、实时事件/相位算法方法综述、机器学习临床预测报告规范或 EEG benchmark 规范。
- 用途：界定术语、比较字段和报告规范。
- 边界：背景综述不能代替某一算法的原始性能、时延或人体有效性证据。

## 七、统一全文提取表

每篇候选完成全文准入后至少填写以下字段：

| 类别 | 必填字段 |
| --- | --- |
| 题录与版本 | 英文原题、作者、年份、期刊/会议、DOI、出版社版/作者稿/预印本 |
| 对象 | 样本量、人群、疾病、中心、记录夜数 |
| 输入 | 原始 EEG/时频图/手工特征、导联、参考、采样率、辅助模态 |
| 标签 | AASM/R&K、标准版本、S3/S4处理、评分者与共识方式 |
| epoch与窗口 | epoch长度、重叠、上下文长度、更新步长、缓存长度 |
| 因果性 | 滤波、归一化、网络、上下文和后处理是否访问未来 |
| 划分 | 随机epoch、subject-wise、LOSO、跨数据集、外部测试 |
| 阶段指标 | accuracy、macro-F1、balanced accuracy、κ、逐类F1、混淆矩阵 |
| 事件指标 | sample/event口径、匹配规则、precision/recall/F1、假阳性/小时、边界误差 |
| 相位指标 | 参考真值、圆周均值/离散度、目标窗命中、低幅条件、补偿链路 |
| 不确定性 | 校准方法、校准指标、拒绝阈值、覆盖率与拒绝后性能 |
| 部署 | 参数量、模型大小、内存、缓冲、时延、功耗、平台与数值精度 |
| 限制 | 数据泄漏、未来访问、标签不确定性、失败条件、不可比较项 |

缺失字段统一填写 `待核实`；不得按模型名称、代码习惯或相似论文推断。

## 八、候选排序规则

候选排序依次考虑：

1. 是否直接填补 R1–R5 的必需缺口；
2. 是否为人体睡眠 EEG 原始研究；
3. 是否具备完整全文和可定位方法/结果；
4. 是否采用受试者隔离或外部验证；
5. 是否报告逐类、事件或圆周统计；
6. 是否有真实在线、流式或设备端实测；
7. 是否同行评审正式发表；
8. 期刊质量信息仅在可核验时作为次级排序因素。

同一方法的多篇论文优先保留：原始提出论文、独立外部验证和在线部署论文；同团队的小改版或重复数据研究只在提供不可替代字段时纳入。

## 九、最终组合要求

理想的 14–16 篇新增组合为：

| 任务 | 理想新增数 | 最低数 |
| --- | ---: | ---: |
| R1 严格因果在线 EEG 分期 | 3 | 2 |
| R2 标签标准与评分一致性 | 3 | 2 |
| R3 数据泄漏与划分 | 2 | 2 |
| R4 事件检测 benchmark | 3 | 2 |
| R5 相位真值与圆周统计 | 3 | 2 |
| R6 校准与拒绝输出 | 2 | 1 |
| R7 端侧部署实测 | 2 | 1 |

允许同一篇高质量研究同时完成两个任务；合并计数后，新增不重复全文保持在 14–16 篇。若候选只能提供离线总体准确率，则不计入 R1、R4、R5、R6 或 R7 的完成数量。

中文文献建议分散配置，避免全部集中于背景介绍：

- R1、R3、R4、R5、R6 或 R7 中至少覆盖 2 个任务组；
- R2 标签标准与评分一致性优先配置 1 篇可核验的中文标准、指南或本土评分一致性研究；
- 背景文献最多只有 1 篇中文来源可计入本轮中文最低配额，其余中文配额应由标准、原始研究或可直接支撑技术比较的方法研究完成；
- 中文研究若与英文研究在数据集、导联、标签、划分或运行模式上不一致，仍标记 `⚠️不可直接比较`，不得另设较宽松的比较标准。

## 十、2.2 重构放行条件

只有满足以下条件后，才生成继承 v5 要求的下一版本正文：

- 五段算法功能链均至少有一项直接证据；
- 阶段、事件和相位三类任务各覆盖至少三种方法路径；
- 严格因果在线分期至少2篇，理想3篇；
- 数据泄漏/划分按 R3-A/B/C 分层证据链覆盖（机制 ≥1 篇、受试者隔离实践 ≥2 篇、外部验证 ≥1 篇）；随机 epoch 与 subject-wise 的直接比较允许保持 1 项 gap，且不进行两种划分的定量差值归纳；
- 标签标准/评分者差异至少2篇；
- 校准或拒绝输出至少1篇，理想2篇；
- 事件比较可说明匹配规则和延迟时间零点；
- 相位比较可说明参考真值和圆周统计；
- 所有比较条目能填写统一全文提取表；
- 中文文献数量按向上取整达到最终不重复文献总量的 20%，且至少 2 篇中文来源达到 A 级；
- 中文来源至少覆盖 2 个 R1–R7 技术任务组，不能全部作为背景综述或概念定义；
- 数据集、导联、标签或划分不同的结果不形成准确率排名；
- 无 EEG 双向 Mamba 继续保持“邻近技术证据”角色；
- 下一版本完整继承 [[review/综述正文v5草案-2.2至6.5]] 的主归属、跨章去重、邻近证据分层及全部 `gap`。

## 十一、后续执行步骤

### F组：整批Ingest后的判定顺序

1. 先核验题录、全文完整性、重复版本和语言属性；
2. 逐篇填写第七节统一提取表；
3. R1逐层检查预处理、网络、后处理和运行验证是否访问未来；
4. R2核对标准版本、S3/S4映射和评分者协议；
5. R3只作分层证据链，不虚构随机epoch与subject-wise定量差值；
6. R4登记事件真值、匹配容差、假阳性/小时和延迟时间零点；
7. R5登记离线参考相位、预测窗、圆周统计与刺激到达时间；
8. R6区分概率校准、错误排序、拒绝输出和人工复核；
9. R7区分模型推理时间与端到端时延，并登记硬件、内存和功耗；
10. 最后计算中文不重复全文比例、A级中文数量和R1–R7覆盖，再决定是否放行2.2重写。
