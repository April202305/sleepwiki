# Henin 等（2019）：增强睡眠振荡但未改善记忆

## 基本信息
- 类型：两项健康人体随机被试内交叉研究；第二项双盲
- 原始文件：`raw/inbox/henin-2019-clas-oscillations-not-memory.pdf`

- 作者/年份：Simon Henin 等；2019
- 英文原题：Closed-Loop Acoustic Stimulation Enhances Sleep Oscillations But Not Memory Performance
- DOI：10.1523/ENEURO.0306-19.2019
- review_sections：["3.2", "3.3", "6.1"]

## 核心摘要

午睡空间导航实验（n=12）和整夜词对实验（n=19）均增强慢振荡与纺锤活动，但刺激相对 sham 均未改善行为表现。第二项尽量复现既往词对协议并采用受试者与实验者双盲。[[intervention/闭环听觉刺激]]（PDF 第 1–2、11–14 页）

## 方法与发现
- 两项研究均为随机被试内交叉；生理效应与行为终点出现分离，不能以 EEG 增强替代认知获益。[[intervention/闭环听觉刺激]]（PDF 第 1、7–14 页，Tables 2–6）
- 作者讨论了任务特异性、局部记忆重激活和系统不应期等可能解释，但这些解释不是该研究直接证明的机制。
